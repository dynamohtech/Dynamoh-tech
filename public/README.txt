Drop your real assets in this folder before deploying:

- profile-photo.jpg  (optional — only needed if you want a real photo
  instead of the "EA" initials mark used throughout the site)
- og-image.png       (1200x630) — the image shown when this site's link
  is shared on LinkedIn/Twitter/etc. Referenced in app/layout.js.
  A quick Canva template works fine for this.
- favicon.ico        (optional) — browser tab icon.
